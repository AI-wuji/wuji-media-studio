## 产品介绍

无极影像工坊把常用的 AI 文本、图像和视频创作流程放进一个轻量桌面界面。你可以配置自己正在使用的服务商与模型，编辑提示词、选择模板、添加参考图片，并在本机查看生成结果。

应用本身负责组织创作流程和连接服务；实际生成由你配置的 API 服务完成。不同服务商开放的模型、参数和能力可能不同，请以服务商提供的模型列表与接口说明为准。

## 创作工作区

| 工作区 | 能做什么 |
| --- | --- |
| **文本** | 与已配置的文本模型多轮交流，整理创意、构思画面或继续修改想法。对话记录保存在本机。 |
| **图像** | 连接图像 API，设置画面比例与 1K、2K、4K 尺寸，选择提示词模板并生成图像。 |
| **视频** | 使用 Seedance、H3 等兼容视频模型，组织镜头提示词，添加多张参考图并选择参考图角色。 |
| **RunningHub** | 从侧栏快速打开 RunningHub AI 应用页面。 |

### 图像创作

- 提供常用画幅比例和 1K、2K、4K 尺寸选项。
- 内置图像提示词模板库，可按分类浏览、搜索并查看模板预览。
- 支持把原始想法扩写成更完整的生成提示词，并手动补充元指令。
- 支持 GIF 输出请求；是否能得到动态 GIF 取决于所选服务商和模型的实际支持。应用会检查返回内容，静态图不会冒充动图。

### 视频创作

- 适配 Seedance 与 MiniMax-H3 两种提示词格式，可按服务商实际开放的模型 ID 配置。
- 模板库支持分类、搜索、预览和模板内容查看。
- 支持多张参考图，并提供六种参考图使用方式：智能、首尾帧、仅首帧、仅尾帧、首帧加多参、全部参考。
- 可配置画幅、时长、生成类型、镜头数、参考素材说明与手动元指令。

### 文本与提示词

- 文本工作区支持连续多轮对话。
- 图像和视频工作区可将创意扩写为结构清晰、可直接提交给模型的提示词。
- 可添加本机自建元指令，并选择跟随预设、自建优先或关闭模板；自建内容保存在本机。

## API 设置

在设置面板中分别配置文本、图像和视频 API：

1. 选择常用服务商，或使用自定义兼容接口。
2. 填写 API 地址、密钥和模型 ID；模型列表支持从服务商拉取，也可手动输入。
3. 保存后即可在对应工作区选择模型并开始创作。

API 密钥保存在 Windows 凭据管理器中；连接地址、模型配置等保存在当前 Windows 用户的应用配置目录。提示词与生成请求会发送给当前所选 API 服务商处理，请根据服务商的隐私政策和计费规则使用。

## 常见问题

**模型列表没有显示我需要的模型？** 先确认服务商的模型列表接口可用；也可以在设置中手动填写模型 ID。

**为什么 GIF 结果是静态图？** GIF 直出需要服务商返回多帧 GIF。若所选模型仅返回单帧图像，应用会提示结果不是动态 GIF；转换单张图像不能产生真实运动。

**更新后个人设置还在吗？** 应用配置与密钥存储在 Windows 用户数据区域；自建模板与对话数据保存在本机 WebView 数据中。正常覆盖升级不会清理这些用户数据。

**API 请求由谁处理？** 文本、图像和视频生成请求会提交至当前工作区配置的服务商，生成速度、模型能力和费用由服务商决定。
